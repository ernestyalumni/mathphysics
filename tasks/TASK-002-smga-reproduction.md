# TASK-002 — Reproduce SMGA stripped amplitudes A_123 … A_123456

## Goal

Numerically reproduce the single-minus stripped amplitudes A_{123} through A_{123456} of
arXiv:2602.12176v2 (SMGA) in the half-collinear regime R₁, matching the paper's values /
structure. This is the benchmark reproduction that anchors all discovery claims.

## Inputs / starting points

- Paper source: `workspace2/Data/Public/papers/physics/arXiv-2602.12176v2/SMGA.tex`
  (if that path is stale, search `Data/` for `SMGA` / `2602.12176`).
- Existing attempt: `amplitudes/scripts/08_smga_stripped_amplitudes.py` — read first;
  extend rather than duplicate.
- Notes: `amplitudes/08-literature-review.tex`.
- Berends-Giele engine from TASK-001.

## Steps

1. Encode the half-collinear regime R₁ kinematics exactly as the paper defines it
   (their parametrization, their sign conventions — copy definitions into docstrings with
   equation numbers).
2. Compute the stripped amplitudes A_{123} … A_{123456} from the Berends-Giele engine
   evaluated in R₁; strip the prefactors exactly as the paper does.
3. Compare against the paper's explicit expressions term by term. Record relative errors.
4. Write results table (n, config, computed value, paper value, |rel err|) to
   `amplitudes/results/smga_reproduction.md` (create `results/`), generated by the script,
   not by hand.

## Definition of done

`uv run python amplitudes/scripts/08_smga_stripped_amplitudes.py --verify` exits 0, prints
a table with all reproduced amplitudes at |rel err| < 1e-8, and writes
`amplitudes/results/smga_reproduction.md`.

## Notes for the agent

- If a value disagrees, do NOT tweak signs until it matches. Localize the discrepancy
  (which n, which term), check convention mismatches (mostly-plus vs mostly-minus, ⟨⟩[]
  ordering), and document the resolution in the results file.
