# YM-G06 — Feasibility estimate for a computer-assisted finite-size criterion

Tier T3 · Workstream C · Depends on: YM-R02, YM-R07 · Review: T3 · Budget: one session. Estimate only; no implementation.

For each: the inequality, the box size it needs relative to the correlation length, and what would have to be computed rigorously. Then estimate, for SU(2) in d = 4 at the smallest β where no gap proof exists (from YM-R07), the box size, the dimension of the integral, and the cost with interval arithmetic or certified Monte Carlo bounds. Verdict: feasible / infeasible by N orders of magnitude / feasible only after an RG step, with the arithmetic shown.
