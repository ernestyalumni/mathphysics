# Mathematical physics capability registry

registry.json records 46 bounded capability families, mathematical domains, proposed independent acceptance examples, dependencies and source references. Entries distinguish existing partial Rust code from planned native capabilities and optional external oracles. A registry entry is not an implementation or a claim of vendor parity.

This is the initial F17 audit under the user-approved Rust platform plan. Broader mathematical capabilities remain extensible; the registry does not limit future work to the first textbook or these 46 families. Source hashes and references identify inspected inputs. Fresh executed baseline evidence is separate in docs/verification/PLATFORM-WAVE1.md.
